# 下一轮生产验收清单

这些是仍须执行的检查，不是本次已通过结果。任何失败应保留原始数据、日志与可复现步骤，不清空数据库掩盖问题。

## 构建关

联网安装完整依赖，固定锁文件；`npm run check` 和 `npm run build` 必须成功；React 19、Electron 与 Node 实际版本必须写入报告。审计依赖和基础镜像后，分别生成并签名 macOS/Windows/Linux 需要交付的安装包。包内旧版 React 体验运行时不得进入生产发布。

## 数据和同步关

对真 PostgreSQL 从空库执行迁移，使用非超级用户执行所有端点。两名测试用户分别创建对象、来源、资产、向量，交叉读取／修改应失败。验证超级用户误配会被部署检查识别，而非误以为 RLS 天生挡住所有账号。

桌面 A、桌面 B、iOS、Web 登录同一测试账号。离线 A 捕获三条再重启；B 修改另一属性；恢复 A 网络后核验原始 captured_at、对象数量、outbox ACK、重复提交和 delta 游标。测试两台机器插入不同块、同块冲突、慢设备时钟、删除与旧修改竞争，以及 push 成功但 pull 失败的重试。

验证 tag / placement 的重新添加产品规则、失效 mutation 隔离恢复、历史丢失内容可读。当前实现保留错误队列但没有完整修复 UI。

## 存储关

真实 MinIO 与 CloudBase 分别验证图片、音频、视频直传；应用服务端不能收到媒体二进制。伪造 user_id/storage_key、过期签名、跨用户 asset_id、错误长度／哈希、断网／应用重启应不导致越权或误报成功。检查真实 checksum 而非只信用户声明元数据。验证 CORS、同源 Cookie、HTTPS 和下载 URL 过期。iOS 遇 POST 签名的兼容方案须明确。

## 原生关

Electron 检查 safeStorage、IPC frame、窗口导航限制、系统快捷键、媒体读取和磁盘写入失败。iOS 用 Xcode 编译，至少在一台真实目标 iPhone 上冷启动 20 次，记录从进程启动到可输入的首帧时间，报告 P50/P95 和最慢值，验证文档的 <1秒指标；不得以 Swift 语法成功或 Web 截图代替。

iOS 检查相册权限受限、拒绝麦克风、横竖屏、锁屏后重开、大媒体内存、低电量、连接失败、令牌过期、损坏缓存写保护和队列重试。确认后台退出前的数据确实落盘。

## AI 与规模关

用真实中文样本评估 pg_trgm 和 bge-m3 的召回；验证索引新建／更新／删除，不将过期向量静默当作当前内容。使用实际模型检查 JSON、证据不足沉默、引用存在、重复引用去重、提示注入、防止改写原文、proposal 逐条确认。

至少测试目标对象规模（例如 10,000 / 50,000）下的启动、bootstrap、push/pull、搜索和画布帧率；记录服务端全量 workspace 装载／历史增长的成本。按结果优化，而不是仅凭虚拟列表就声称大库流畅。

## 交付关

从新电脑解压重现步骤；验证 SHA256 清单；做一次包含数据库、对象存储和配置的恢复演练。用户确认未决产品规则后，再把状态从工程版改为正式发布版。
