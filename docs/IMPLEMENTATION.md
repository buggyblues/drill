# 实现对照与工程边界

版本：0.1.0。原始《产品文档》《技术架构》《UIUX设计》《实现提示词》完整保留，未改写成“已完成”文档。

## 核心模型如何落地

对象只有一个主记录。`form` 表达不可变形态，`kind` 表达可以晚些确认的语义角色；`title` 是主体，`body/body_blocks` 是附文。标签、归属、系列是不同概念，没有用统一树状文件夹替代它们。`kinds` 的定义来自数据库；11 个已有语义角色仍承担产品中明确规定的专用行为，自定义种类使用通用属性渲染。

`placements` 只记录同一个对象在某张画布的摆放；分组成员通过该摆放记录的 `group_id` 归属。引用是独立关系，记录来自主体还是附文的哪个块；未解析的双链不会静默生成对象。外部快照不可改正文，资料与 AI 内容不能直接改名成为“沉淀”。

## 数据路径

Web 只保留当前会话内存；不使用 IndexedDB 或 LocalStorage 作为对象库。页面刷新后重新读服务器。

桌面先把变更和乐观展示写进一个 SQLite 事务；网络恢复后推送稳定 mutation ID，确认后删除相应 outbox，再拉取服务器结果，游标与数据在同一个本地事务写入。乐观投影不比较设备时钟，也不决定哪个并发版本胜出。所有冲突规则只存在于 `server/merge.ts`。

iOS 先把捕获和媒体队列原子落盘，再联网上传，缓存最近 150 条及未上传条目。没有段落编辑、版本仓库、客户端合并。Keychain 保存令牌，缓存读取失败时锁住写入，防止误覆盖损坏文件。当前最近列表主要显示文本／形态标识，**不是完整的移动端媒体阅读器**。

两种正式部署都使用 `PostgresRepository` 和一套 SQL。独立的 `DemoRepository` 只服务 `npm run demo` 和契约测试，正式启动入口不会悄悄降级为 JSON 文件库。

## 当前简化，不能当作完整交付的功能

1. **正文编辑器是按段落工作的文本编辑器，不是完整富文本编辑器。** 没有全套 Markdown 可视化、表格、网页剪藏清洗、PDF 阅读器、ASR、OCR、媒体转码、缩略图生成。Web 与 iOS 按文档限制只读正文。
2. **分数索引维护稳定位置，但当前删掉的 placement / 标签墓碑不支持直接复活。** 删除对象／摆放前有风险提示；仍需设计“重新加入”的显式版本语义，而不是清除墓碑碰巧让测试通过。对象恢复／整库导入 UI 尚未提供。
3. **地图算法是实验性实现。** 使用已配置服务的真实向量做确定性种子聚类，区域排布是规则坐标，不是经过评估的降维地图。随机漫步也未做推荐质量评估；无向量服务时不生成看起来很真实的假地图。
4. **向量检索仍是单用户原型规模。** 向量存 PostgreSQL `vector(1024)`，当前精确余弦评分在应用内执行，不是经过性能验证的数据库 ANN；目前按整对象截断嵌入、手动重建，没有完整分块与可靠增量队列。数万对象性能尚未测量。
5. **连接器是手动只读拉取。** 不自动监视目录，不抓取任意页面正文。Chrome 最多读取最近 50,000 条访问记录；按连续同主机、间隔小于 30 分钟分组，不等价于还原浏览器所有标签页的真实会话。Obsidian 深度与文件数量有限制，大文件跳过；Codex 只解析识别到的可见 user/assistant 消息。每次重扫比较来源版本，不是基于系统文件事件的增量采集器。
6. **来源变化保留冻结旧内容并提示，不自动覆盖。** 没有完整的更新版本对比和“导入新快照”向导。连接器配置中的本机路径属于隐私，导出／备份时留意。
7. **媒体链路源码已接，真实服务未联调。** 服务端签发 `{user_id}/{asset_id}`，客户端直传；当前提交核验主要依赖 HEAD 大小与上传时声明的 hash 元数据，并非对存储中的全部字节再次做可信哈希计算。iOS 只接受 PUT 签名，POST 表单签名明确报错并保留本地队列。大视频整块读取／IPC 复制有内存压力，尚未实现断点续传。
8. **离线错误队列没有完整管理 UI。** 服务端拒绝整个批次时保留本地数据和错误，不会假装成功。可导出 pending_changes / pending_requests 并备份 SQLite；对永久无效变更仍需开发者诊断，未实现自动隔离与逐项修复界面。
9. **原生产品化尚未完成。** 没有自动更新、崩溃遥测、应用签名、公证、商店分发、iOS 分享扩展、后台可靠上传、真机性能验收。
10. **数据库迁移为初始幂等脚本。** `schema_migrations`、`distill_sessions`、`object_assets` 等表提供了结构，但尚未形成版本升级系统、独立提炼会话管理、多附件编辑功能。不能用“建了表”证明相关功能完整。

## 特意没有加入的内容

没有 CRDT、客户端冲突合并、端到端加密、实时协作、全局关系大图、画布自动对齐／分布、公开第三方 API、自动读取用户连接器目录、未配置时的模拟 AI 内容。浏览器窄屏截图也没有冒充 SwiftUI 真机截图。
