# UI / UX 设计

## 总则

**一、三个维度正交。**

```
操作方式（快捷键 / 拖拽 / 粘贴） × 展示形式（列表 / 画布 / 看板） × 视图（新增 / 行动 / 领域…）
```

**不要把操作方式做成按钮摆在面前。** flomo 原话：「我特别讨厌产品一上来给用户三个输入按钮：打字、语音、拍照……这是把困难丢给用户，是一种责任推卸。」〔flomo〕

**二、默认不选类型。**

`+` 是「投入一份东西」，不是「新建节点」。你在应用里永远不判断它是什么——那是提炼时的事。

**三、画布不是起点。** 想法的入口是列表。〔Heptabase〕

**四、界面靠留白和背景色差分，不靠边框。**

## 一、参考来源与意图

**这是本项目的设计要求，来自项目作者的原话：**

> 我需要的就是这种**极简高级**的设计风格。整体的**页面分栏参考 Codex**，Capacities.io 参考**对对象的很多交互和展示**，Heptabase **重点参考画布**。

### Heptabase → 画布（重点）

| 参考什么 | 具体 |
|---|---|
| **底色层次** | 白板底是米白（约 `#fafaf9`），**卡片是纯白**——层次靠这个差，不靠边框 |
| **卡片** | 圆角 8–12px，极浅边框 + 浅阴影，在白底上「浮」起来 |
| **卡片色变体** | 橙 / 蓝 / 浅黄 / 浅绿的**淡底**，用来表达「这类东西」 |

| **连线** | 细、深、曲线、带箭头、起点一个小圆点。不要粗线，不要花式箭头 |

| **缩放控制** | 右下角，`ash` 小字 |
| **面包屑** | 顶部「图标 + 路径 + ···」，用来知道自己嵌套在哪一层 |
| **它的克制** | 白板早期刻意不做手写、形状、线条，先做卡的复用和层级——这是它的历史，也是它的策略 |

## 二、设计语言

**目标：极简、高级、能长时间看。** 下面的数值不是拍的，是从三个参照产品的实际实现里提取的。〔Capacities 的设计令牌来自 refero.design 的可读导出；Heptabase 与 Codex 来自真机截图实测〕

### 色板（浅色）

**中性阶（六级，这是整个界面的骨架）**

| 名称 | 值 | 用途 |
|---|---|---|
| `ink` | `#1a1a1d` | 标题、主体文字、填充按钮底 |
| `charcoal` | `#454447` | 导航标签、链接、次级深色 |
| `graphite` | `#5c5959` | 正文、说明 |
| `ash` | `#a7a2a1` | 元数据、时间、低强调文字 |
| `stone` | `#ecebea` | 可见的边框、结构线 |
| `porcelain` | `#f5f4f3` | 极细分隔线、浅中性填充 |
| `paper` | `#ffffff` | 页面底、卡片面 |

**注意 `ink` 是 `#1a1a1d`，不是纯黑。** 这是"高级感"最便宜的一招——纯黑在浅底上会显得硬。

**暖色（少量，用于强调和选中）**

| 名称 | 值 | 用途 |
|---|---|---|
| `butter` | `#fffbeb` | 暖色对象磁贴、选中态 |
| `honey` | `#fde68a` | 暖色 pill 的边框 |
| `amber` | `#945424` | 橙色文字强调 |

**对象色（ten kinds 用，只做 accent，不做填充）**

每个 kind 一个色相，但**饱和度压得很低**。用法有三种，选一种，不要混：

```
用法 A  卡片左侧 2px 竖线
用法 B  图标着这个色，其他都是 ink
用法 C  极浅背景 tint（-50 级别）+ 同色系 1px 边框
```

**Capacities 的明确禁令可以直接抄**：

> 不要用饱和的蓝、紫、绿、红做页面级颜色；浅蓝和淡紫**只用于对象卡片的 accent**。

### 字体

| 角色 | 字体 | 字号 / 字重 / 行高 / 字距 |
|---|---|---|
| 页面大标题 | Inter | 48px / 700 / 1.05 / **-1.44px** |
| 区块标题 | Inter | 36px / 700 / 1.25 / -0.9px |
| 小标题 | system sans | 18px / 600 / 1.56 / -0.45px |
| 正文 | system sans | 16px / 400 / 1.5 |
| 导航 | system sans | 14px / 400 / 1.43 |
| 小标签 | system sans | 14px / 600 / 1.43 / +0.35px（大写时） |
| 元数据 | 等宽 | 12px / 400 / 1.33 |

**两条关键规则：**

**一、大字号必须有负字距。** 48px 用 -1.44px，64px 用 -1.92px。**没有负字距的大标题会显得廉价**——字距一松，字就散了。

**二、界面文字用系统字体（-apple-system / Segoe UI），只有大标题用 Inter。** 这样界面文字在不同系统上"就是本机的样子"，而大标题保持品牌感。〔Capacities 就是这个分工〕

### 间距

| | 值 |
|---|---|
| 基准单位 | **4px** |
| 元素间 | 6px |
| 紧凑组合 | 8 / 12 / 16px |
| 卡片内边距 | **24–28px** |
| 区块间距 | **64–73px** |
| 内容最大宽度 | 1280px（正文列更窄，约 700px） |

**间距要慷慨。** 这是"高级"和"业余"最大的区别——业余的设计到处都紧，专业的设计敢留空。

### 圆角

| 元素 | 圆角 |
|---|---|
| 链接、按钮 | **6px** |
| 输入框、图标磁贴 | **8px** |
| 图片、媒体 | 12px |
| **卡片** | **16px** |
| 大卡片、面板 | 20px |

**按钮不要用胶囊圆角（pill）。** 这是 Capacities 的明确禁令——胶囊圆角会让界面显得轻浮，和"思考工具"的调性不符。

### 阴影

**只有一档：**

```css
box-shadow: 0 1px 2px rgba(0, 0, 0, 0.04);
```

**就这一档。** 不要多层阴影、不要彩色阴影、不要 hover 时加重阴影。**层次靠背景色差和边框，不靠阴影。**

白板上的卡片可以稍重一点：`0 1px 3px rgba(0,0,0,0.06)`——因为白板有底色，卡片需要"浮起来"。

### 七条硬规则

```
1  近黑不纯黑（#1a1a1d）
2  只有一档阴影
3  按钮圆角 6px，不用胶囊
4  彩色只做 accent，不做页面级颜色
5  大标题必须有负字距
6  间距用 4 的倍数，卡片内边距 ≥24px
7  分隔用极浅线（porcelain #f5f4f3）或干脆不用线
```

## 四、左栏：导航

**300px，四段，用间距而非分割线分组：**

**第一段 · 常驻视图**（行高 36px，图标 16px + 标签 14px）

```
◇ 新增        过去一段时间进来的一切
◉ 行动        所有 kind = 行动
✳ 洞察        AI 洞察的入口
```

**第二段 · 领域树**（分组标题 12px `ash`，条目缩进 16px）

**第三段 · 画布**（最近 5 张 + 「全部画布」）

**第四段 · 连接器**（默认折叠成一行，显示新增数）

```
▸ 连接器  12
```

展开后每行一个，**右侧显示上次同步时间**。三周没产出的要显出来：

```
  Codex          12 条
  Obsidian       上次同步 21 天前   ← ash 色
  Chrome         3 条
```

**展开即视为看过**——锚点前移，不再高亮。**不代表任何操作。**

## 五、中栏：内容

**顶栏只有两样：时间窗口和搜索。** 高度 48px，底部 1px `porcelain` 线。

```
[今天] [本周] [本月] [自定义 ▾]        🔍
```

选中的时间窗口：`ink` 文字 + `butter` 底 + 6px 圆角。未选中：`graphite` 文字，无底。

### 列表

行高 **44px**，左右内边距 20px，行间不用线，靠 hover 时 `porcelain` 底区分。

```
▸ 小红书封面为什么用浅色会糊          #设计       8/12
▸ 口语练习一直没开始                  #英语       8/11
▸ 关于「我应该先做哪个」的又一次纠结    #自媒体     8/11
   ↑ ink 16px                        ↑ ash 12px  ↑ ash 12px
```

**左侧一个 6px 的 kind 色点。** 这是列表里唯一的彩色。

### 画布

**只做三件事**：拉进来、摆位置、连线。〔Heptabase 的呈现降级〕

- 白板底 `#fafaf9`
- 卡片纯白，圆角 10px，`0 1px 3px rgba(0,0,0,0.06)`
- 左侧 40px 工具栏：选择 / 连线 / 文本 / 图片 / 框选 / 搜索 / 更多
- 缩放控制在右下角，`ash` 小字
- 顶部面包屑：图标 + 路径 + `···`
- **不做对齐、分布、自动布局、模板、连线样式**
- **嵌套画布渲染到当前层为止**，进入才加载下一层

### 看板

按 `label` 属性分列。列头 14px `graphite` + 数量 `ash`。卡片同列表行，宽度自适应。

**只有声明了 `label` 属性的 kind 才有看板入口。** 没有就不显示——**不要给一个空看板**。

## 六、右栏：上下文

**360px，两个角色，按有没有候选切换。**

### 有候选：提炼

```
提炼                        12 条
────────────────────────────────
小红书封面为什么用浅色会糊
  类型   [沉淀 ▾]    ← AI 建议：沉淀
  归属   [自媒体 ▾]
  标签   [+ 设计] [+ 验证]
  ────────────────────────────
  [采纳]  [改一下]  [跳过]
```

**没有「全部采纳」按钮。** 那条路会让提炼变成点两下的事。

**不显示剩余数量、不显示进度条。**

### 没候选：上下文

```
相关
  口语练习为什么总是推迟          8/11
  我第三次写「先做哪个」           7/28
────────────────────────────────
局部图
  → 它引用了 2 条
  ← 被 1 条引用
────────────────────────────────
洞察   [点一下]
```

**洞察不自动跑，点之前什么都不显示。** 跑完没内容可说就显示「这条暂时没什么可说的」——**允许沉默**。〔flomo〕

## 八、类型的视觉区分

**每个 kind 一个图标 + 一个色相。** 从 `kinds` 表读。

**用法统一为「6px 色点 + 图标着色」**，其他部分都是 ink。不要用彩色填充、不要用彩色文字、不要用彩色边框包围整块。

| kind | 图标 | 色相 |
|---|---|---|
| 领域 | ▣ | 靛 |
| 项目 | ▤ | 蓝 |
| 画布 | ▢ | 青 |
| 分组 | ⬚ | 灰 |
| 行动 | ◉ | 橙 |
| 产物 | ◆ | 紫 |
| 沉淀 | ● | 绿 |
| 资料 | ○ | 灰蓝 |
| 想法 | ◌ | 黄 |
| 自我认知 | ◎ | 红 |
| **AI生成** | ✳ | **浅灰 + 虚线左边框** |

**三种必须一眼看出的状态：**

| | 怎么标 |
|---|---|
| **`AI生成`** | 虚线左边框。**永远和「你写的」在视觉上分得开** |


## 十、状态

### 空状态必须说人话

| 位置 | 空的时候 |
|---|---|
| 局部图 | 「这条还没有关联」**（不要画一个孤立的点）** |
| 相关 | 「还没有足够相似的内容」 |
| 洞察 | 「暂时没什么可说的」**（允许沉默）** |
| 新增 | 「今天还没有新东西」 |
| 看板 | **不显示入口** |
| 搜索 | 「没找到。试试用你自己会写的词？」 |

空状态的样式：居中，图标 `ash`，文字 14px `ash`。**禁止出现「暂无数据」。**

### 加载

- 列表和详情：**乐观更新**，本地先写，后台同步
- 相关和搜索：骨架屏，超过 300ms 才显示
- 洞察：**显示"在读"，不是转圈**——它可能要十几秒
- 连接器：显示进度和「已拉取 N 条」

### 失败

**同步失败不弹窗。** 左栏底部一个 `ash` 状态点，点开看详情。

**离线是可用的状态，不是错误。**

**冲突丢数据必须可见**：`conflicts` 里 `resolution = 'lost'` 的记录，在对象详情显示一行「有一次修改被覆盖了，点开看」，用 `amber` 文字。

## 十一、键盘

**原则：预览是临时的，进入才是持久的。**〔Heptabase 的级联设计〕

| | |
|---|---|
| `↑ ↓` | 列表里移动 |
| `⏎` | 打开小窗预览（浮层） |
| `⌘⏎` | 打开成右栏（持久） |
| `⌘⇧⏎` | 进入嵌套画布 |
| `esc` | 退回上一层 |
| `Tab` / `⏎` | 导图里长节点 |
| `⌘K` | 全局搜索（含命令） |
| `⌘⇧Space` | 快速写 |
| `⌘Z` | 撤销（**包括属性修改**） |
| `/` | 在正文里插入（引用、标签、类型捷径） |

**`⌘⏎` 和 `⌘⇧⏎` 的区别要严格**：前者是「看看」，后者是「进去」。混了就会一直迷路。

---

## 十二、移动端

**只有三件事：看、搜、捕获。**

- **没有画布、没有编辑附文、没有连接器**
- 捕获只写主体，**存进 outbox，联网后推**
- 底部一个浮动按钮，圆形，`ink` 底 + `paper` 图标，56px
- **冷启动 < 1 秒**。超过 1 秒捕获就退化成「回头再说」，然后就是不做了

---

## 十三、性能约束

| | 目标 | 为什么 |
|---|---|---|
| 冷启动（移动端） | **< 1s** | 超过就没人捕获 |
| 打开对象 | < 100ms | 本地库直读 |
| 相关（向量） | < 500ms | pgvector 精确搜索 |
| 画布渲染 | **只到当前层** | 嵌套深了会卡 |
| 列表滚动 | 60fps，虚拟滚动 | 几万条 |
