# 文档冲突、暂定决策与待确认事项

这里区分“按后文明确约束处理”和“为使工程可运行的暂定实现”。暂定决策不代表用户已经逐项批准。

原始提示词要求先逐里程碑确认；本次外层请求要求直接实现并打包，因此交付了工程，同时保留未决问题和未完成验收，而不是把原提示词删除。

## 按明确约束处理

| 冲突点 | 本版处理 |
|---|---|
| 早期 group 可能被理解为跨画布集合，后文指定区域 | 按 `placements.group_id`，每张画布独立，不维护全局成员集合 |
| 早期不落库 AI 与后文明确 `ai_output` 新对象 | AI 生成另建 ai_output，引用源对象；不能覆盖已有正文；属性必须经过 proposal 用户确认 |
| 为实现离线而在三端各写一套合并 | 拒绝。只有服务端 `merge.ts` 做冲突处理，客户端仅记录、推送、拉取 |
| “捕获时刻”和“服务器写入时刻”混淆 | `captured_at` 保留客户端时间，`created_at` 由服务器生成；筛选按保存的用户时区 |
| 动态 kinds 与若干专用语义行为 | kinds 定义存数据库；通用属性动态渲染；文档中的 action / self / material 等角色继续有专用约束 |
| 演示库是否算第三种后端 | 不算。它明确只供本机体验／契约测试；两种正式后端均为 PostgreSQL |

## 尚待产品确认的暂定值

相关内容默认余弦阈值为 `0.65`，随机漫步跳转比例为 `0.15`；可用环境变量调整，没有学习效果依据或用户评估支持，不能宣称为最佳值。

AI 一次最多读取 24 个候选对象，附文做截断，默认最多输出 1,800 token。采用通用 JSON chat-completions 契约，只是适配边界，不代表任意模型服务都兼容。无模型时明确不可用。

iOS 最近列表取 150 条；录音、图片、视频采用 256MB 界面上限。这些是工程保护值，不是经过真机测量后确认的产品容量。缓存 150 条也不自动保证冷启动小于一秒。

Chrome 用“连续同主机、相邻访问间隔小于 30 分钟”作为会话聚合近似。复杂多标签浏览是否应以 eTLD+1／任务主题聚合，需要用户确认和真实样本评估。

认知地图采用种子聚类与规则布局，避免在不连接模型时伪造主题。原文没有最后确定的聚类方法；当前入口属于实验性功能。

## 发布前必须确认

删除后“重新添加标签／重新放到画布”的墓碑语义；来源新版本是否保留为新对象、如何比较；真实模型选择和隐私／费用边界；CloudBase 身份令牌来源与自动续期流程；长期资产备份和恢复；移动端媒体显示粒度；地图和漫步是否继续采用当前实验方案。

这些未决项在代码中未通过伪造后台任务、模拟成功或空白“已完成”按钮掩盖。
